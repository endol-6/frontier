                CPU 3人の手札および未ドローの発展カード山札は ES2022 プライベートクラスフィールド（#privateVault）クロージャ内に封印されており、window オブジェクトや公開ステートから開発者自身であっても参照できません。
              

              

            

          

        


        
        

          
本番環境アクセス制御ルール（Firestore Security Rules / PostgreSQL RLS）

          
// Firestore セキュリティルール: 本人の uid 以外の private ドキュメント読み取りを完全拒否
match /artifacts/{appId}/users/{userId}/pioneers_private/{roomId} {
  allow read, write: if request.auth != null && request.auth.uid == userId;
}
match /artifacts/{appId}/public/data/pioneers_rooms/{roomId} {
  allow read: if request.auth != null; // 公開盤面と手札「合計枚数」のみ格納
}
